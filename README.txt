Muthuraj J Portfolio Website

Files
- index.html: Complete responsive portfolio website
- Muthuraj_J_Resume.pdf: Downloadable resume linked from the website

Open locally
1. Extract the ZIP file.
2. Open index.html in a web browser.

Publish options
- GitHub Pages: Upload the files to a repository and enable Pages.
- Azure Static Web Apps: Deploy this folder as a static site.
- Any hosting provider: Upload index.html and Muthuraj_J_Resume.pdf to the same folder.

Customization
- Replace the contact links in index.html when LinkedIn or GitHub profile URLs are available.
- The website uses no external libraries, images, or fonts.
